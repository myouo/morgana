# 文档入口

日常入口保持在以下几份文档中：

| 文档 | 用途 |
| --- | --- |
| [贡献指南](../CONTRIBUTING.md) | 安装、改动位置、翻译规则、测试与 PR |
| [当前状态](../STATUS.md) | 已发布范围、版本与当前验证边界 |
| [复刻差异](REPLICA_GAPS.md) | 尚未完成的行为与表现差异 |
| [开发说明](DEVELOPMENT.md) | 原资料准备、本地主入口与生成基线 |
| [架构](ARCHITECTURE.md) | 源组织、解析、转换和 SDK 的职责 |
| [翻译指南](../locales/README.md) | PO、控制标记与稳定文本身份 |
| [测试说明](../tests/README.md) | 单元、原资料、浏览器和线上回归的前置条件 |
| [工具导航](../tooling/README.md) | 编译、校验、迁移与发布工具分组 |
| [部署说明](../deployment/README.md) | 正式、预览、鉴权回归环境 |

[推进计划](REPLICA_PLAN.md)记录剩余复刻工作；[章节目录说明](CHAPTERS.md)记录PO整理的来源规则。

`evidence/` 保存历次验收和当时实际执行的命令，旧端口、版本及阶段结论按记录日期理解。项目入口整理后，专项浏览器配置位于 `tests/config/`，阶段脚本直接按[工具导航](../tooling/README.md)调用；历史记录不会重新改写为新的验收事实。

早期序章/第一门设计与性能记录只用于追溯，不作为现在的安装步骤。当前功能范围以 STATUS、差异清单和最近一次对应验收为准。
