# 第四门八语分支、结局和旧档

2026-10-31。第四门正文已从原章头接到 scenario5.ks:*start；三种坏结局内容
分别读到其 first.ks 原标题跳转边界。所有内容仍为新周目支持集；这里没有
加载第五门或执行原标题脚本，正式1→2→3主线仍停在search入口。

八种语言均编译相同的有限源控制树，保留各译本正文、字体、标题数量及
控制差异。前三门和旧第四门主体代码不变；旧终点的控制台账追加1ms接续，
不删旧槽或重置进度。数据仍经实际tarball/public exports使用同一SDK Core。

实现：

- 校验源码的 memory1 && memory2 条件，用标准branch/choice/call降低；只有
  两段记忆都有时才出现第三选项。七次单项选择和后面的双项选择也保留。
- 接入badend1/2/3整理PO及原source profile标记。共同成就检查从共享Steam
  宏解析为SDK profile表达式；八个条件齐全才设置成就，不执行TJS/Steam。
- 补SDK G3-14实时音源循环链接，M-4 SLI只按原采样帧/采样率解析；启停不
  重建音源、不倒跳已经经过的链接点。存档保留模式及来源，恢复仍replay从0。
- 补全屏文本框、居中/重置字体；法语多行菜单及额外的p确认保留。确认使用
  SDK透明正文窗的无字等待，图片中的选择文字不重复绘制，等待不录入历史。
- 自动存档只跟随源autosave标签：七语有三个点，日语源没有这些标签，保持
  无自动点；不是强行给每个译本同样的行为。
