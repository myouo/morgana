# 正文整页显示

2026-10-30：用户要求阅读窗口禁止滚动，尽可能一次显示完整正文。原SDK的声明式文字窗统一使用overflow:auto，长页会自动滚到底部。现将ADV改为完整页测量、必要时有界缩排；短页保留原字号。预留超出行高的字体边界；未显出的文字也参与布局，逐字显示不会持续缩小。显式历史/NVL列表仍按其用途滚动。

改动在SDK通用DOM renderer，实例消费真实依赖包；没有在实例复制排版引擎。剧情/确认次数、Program/release/存档身份和原始槽位保持不变。宽度、主题、字号偏好和字体准备后重算，图文存档捕获采用同一布局。

## 验证方法

- SDK `pnpm check`、371单元、13相关真实浏览器通过；npm白名单270文件/605766压缩bytes。生产e8941e6，实包d7ce3fb67fddbca7666c7f45689dae696f5bfa76c6035db5598164cb4c32fa0c。
- `FATA_FIT_LOCALES=zh,en,fr,it,jp,ko,pt-br,ru pnpm exec playwright test tests/integration-browser/text-fit.spec.ts --config playwright.integrated.config.ts --workers=2`：从冻结模块取每个正文身份的最长续文，以实际字体和最窄原生正文窗构造有界标准Program，通过SDK Core/DOM逐页检查字形边界与scroll尺寸。这是保守几何探测，不冒充整条源剧情或原作逐像素认证。
- `pnpm door2:verify zh`生成真实源路线上较长正文切点；`FATA_REUSE_SERVER=1 pnpm exec playwright test tests/door2-full-browser/text-fit.spec.ts tests/door2-full-browser/rule-recovery.spec.ts --config playwright.full-door.config.ts`验证1.5倍偏好、滚轮、图文保存/刷新和旧问题恢复。偏好变更的150ms滚轮保护保留；测试先等该保护结束，未放宽产品行为。

悬挂在换行末尾且不画笔画的空白不参与字形边界裁决，仍保留在文字和排版中。原矩形极小或正文极长时，完整显示与大字号无法同时保证；没有插入新剧情分页，也不认证原生禁则、竖排或逐像素一致。原始数据/截图/日志和依赖包保持ignore。

初版保守探测误将悬挂空白当成可见内容，某些西文页因此过度缩排；修正对未加下划线的纯空白只保留排版尺寸，不作字形边界判定。新增独立反例保持作者字号。首轮50638页通过属于该修正之前的统计；最终包重新运行全部八语，不混用缩排比例。测试内各语言互不共享Core/字体/存储，最终使用两个受控浏览器worker并行执行以减少等待。

日语的空白首行在缩排中可能重新换行，因此字体leading随每个候选字号重测。本作逐页验收另要求因子至少0.5，防止几何上装下但不可阅读的微缩；该门槛不扩大为对任意4096字符窗口的保证。最终统计以重新验收为准。
