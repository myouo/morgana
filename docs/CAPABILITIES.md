# SDK 能力与当前接入边界

2026-11-05。实例通过实际tarball/public exports运行。当前已发布版本贯通八语序章、一至八门、终章、两次调查和badend1–7，包含通关变体与奖励菜单。范围、实际累计验收及版本见[STATUS](../STATUS.md)和[整合发布](evidence/HISTORY_RELEASE.md)。SDK能力、本作可玩范围、原生存档与原作逐像素认证分别记录。普通/通关第三门电影与残像、心跳染色/模糊已由原参数实时执行。

| 能力 | 当前实现与边界 |
|---|---|
| 长音乐、音效 | versioned-url/HEAD/ETag/Range；独立SE槽与双BGM；源绑定、延迟包络和物理音量夹限；预备音频交接给独立播放源，历史/资源等待保持已有音乐。恢复按声明的replay，不承诺精确媒体seek |
| 保存、刷新 | IndexedDB原子图文存档/当前偏好/进度；手动、快速和源指定自动点；旧32/93页、完整第一门和原两门SDK档显式验证来源并迁移，旧槽保留 |
| 历史与输入 | 鼠标逐次/触控板单手势偏好；历史到底150ms返回、存读档滚轮翻页、顶层右键取消；阅读/回放右键隐藏与首次恢复、富历史/角色分组；本地默认采用512条只读显示/正文保留窗口，不保存未使用的整页rollback；本地收尾候选已接入当前已揭示正文与delay/group中的已显完continue前缀、显式历史追加/hr前后换行和第四门明确重置名字提示及六语普通名字源字号/格式，新版SDK v5去重持久head，累计资料保存刷新通过；源500/2000行缓冲/动态角色缓存仍另验。SDK受控回滚仍可供其他作品使用 |
| 原设置 | 独立已读字速/普通与已读可忽略确认、源滑条/按钮/复选框；当前偏好独立持久，原Default只重置原控件 |
| 解锁、章节与奖励 | 原flag写入持久profile；原章节书十二入口进入同一权威主Program并保留正常后继。通关标题、六按钮菜单、画廊/音乐/后台/隐藏序章已接；中英实际七结局累计解锁通过，其余累计范围另验。SDK临时场景回放仍独立于原章节菜单行为 |
| 角色与演出 | 源部件合成、注册/排序/明暗/对齐、x/y/alpha曲线、复制相位、前后台页、交叉/规则/滚动组转场、雨/花瓣/震动/闪白；中途可存；旧电影与累积残像由SDK参数实时绘制，不使用生成帧 |
| 正文 | DOM正文、源名字图、Ruby、停顿/确认/字速、续段/自动结束、字体/阴影/阶梯淡入、镜头跟随、图文层顺序和截图；ADV正文整页适配，源信件矩形及末写者可冷恢复，原窗口定义不改 |
| 加载 | demand/balanced/chapter/eager通用策略；实例默认4页，可选0/2/4/8，显式隐藏及其后代保留逻辑状态并在显示前准备纹理，alpha淡入仍预备；静态call/return扫描有界；目录与实际驻留预算分开，跨翻页接续未完成预取；驱逐清理资源事实与未消费预备设备 |
| 限时选择 | 第六门单选项使用SDK活动期限与原图片按钮，2000ms点击/超时分支、已用750ms/剩余1250ms的恢复；Native墙钟相位另验。自动保存映射到下一合法正文提示，原生提示前截图时序未认证 |
| 内存 | 空闲分批释放无引用ready资源、保护前看与租约；后台释放Canvas临时工作面并恢复重建；HTTP provider只保留校验后的目录，迁移注册表只缓存原清单；独立显示图共享原缓存/预算、释放后可回收，不改变剧情/存档签名。不是浏览器总RAM限制 |
| 图形兼容 | 一套Pixi场景，WebGL2优先、Canvas后备；正文上下图层分两次输出，额外Canvas计入预算，只有一个图像解释器 |
| i18n与传输 | PO维护、独立语言protobuf文本目录、Schema关联类型/运行时校验；浏览器HTTP传输PB，Core内部使用类型化消息，存储为IndexedDB结构化记录 |
